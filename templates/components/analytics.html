{% comment %} Analytics loader, shared by base.html and marketing_base.html. Nothing from Google Analytics or PostHog is requested, and no analytics cookie or storage key is written, unless the visitor has clicked Accept on the cookie banner (localStorage.cookieConsent === 'accepted'). Decline (or no choice yet) means no analytics script is loaded at all. The choice is also mirrored into a first-party `tmr_consent` cookie so the server can skip its own PostHog events for visitors who have not accepted (see expenses/posthog_utils.py). PostHog is started with autocapture and session recording disabled, and identifies the user only by a salted hash of their id (never email, username or amounts). {% endcomment %} {% if GOOGLE_ANALYTICS_ID or POSTHOG_API_KEY %} {% endif %}
